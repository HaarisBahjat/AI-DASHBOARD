# Quick Reference: Payment Tracking Identification\n\n## How the System Knows WHO Paid WHAT\n\n### **The 4-Layer Identification System**\n\n```\n┌─────────────────────────────────────────────────────────┐\n│ LAYER 1: IDENTITY - WHO IS PAYING?                      │\n├─────────────────────────────────────────────────────────┤\n│ JWT Token → userId                                      │\n│ Example: \"user123\"                                      │\n│ From: Browser localStorage                              │\n│ Scope: Every DB query filtered by userId                │\n└─────────────────────────────────────────────────────────┘\n         ↓\n┌─────────────────────────────────────────────────────────┐\n│ LAYER 2: REFERENCE - WHICH BILL?                        │\n├─────────────────────────────────────────────────────────┤\n│ Due ID → state.due (checkpointer) or DB lookup          │\n│ Example: \"due456\" (5000 Rs bill)                        │\n│ From: LangGraph state persistence                       │\n│ Scope: Specific invoice document                        │\n│                                                         │\n│ NEW LOGIC (if multiple dues):                           │\n│ \"Which bill did you pay for? 1. bill1, 2. bill2, ...\"  │\n└─────────────────────────────────────────────────────────┘\n         ↓\n┌─────────────────────────────────────────────────────────┐\n│ LAYER 3: AMOUNT - HOW MUCH PAID?                        │\n├─────────────────────────────────────────────────────────┤\n│ Gemini Parsing → intentData.paymentAmount               │\n│ Example: 1000 (extracted from \"I paid 1000 rs\")        │\n│ From: LLM intent detection                              │\n│ Scope: Payment record in metadata.payments              │\n└─────────────────────────────────────────────────────────┘\n         ↓\n┌─────────────────────────────────────────────────────────┐\n│ LAYER 4: PROOF - WHEN & VERIFIED?                       │\n├─────────────────────────────────────────────────────────┤\n│ Timestamp → new Date()                                  │\n│ Verification → Razorpay webhook                         │\n│ Example: 2026-08-14T10:30:00Z [PENDING]                │\n│ From: Server clock + payment processor                  │\n│ Scope: metadata.payments array                          │\n└─────────────────────────────────────────────────────────┘\n```\n\n---\n\n## Real-World Example\n\n### **Scenario: User pays Rs.1000 for Rs.5000 bill**\n\n```\nFrontend:\n  User: \"I paid 1000\"\n  Socket: sends { audioBuffer, conversationId: \"conv-abc123\" }\n\nBackend Processing:\n  [1] Authentication\n      JWT token → userId = \"user123\" ✓\n  \n  [2] Due Resolution\n      thread_id = \"conv-abc123\"\n      Loads checkpointer → state.due = { _id: \"due456\", amount: 5000 }\n      OR asks user to clarify if multiple unpaid dues exist\n  \n  [3] Amount Extraction\n      Gemini parses: \"I paid 1000\" → paymentAmount: 1000 ✓\n  \n  [4] Comparison & Decision\n      1000 < 5000 → PARTIAL_PAYMENT ✓\n  \n  [5] Database Update\n      Dues.updateOne({\n        _id: \"due456\",\n        userId: \"user123\"  ← Security check\n      }, {\n        status: \"VERIFYING\",\n        \"metadata.payments\": [\n          { amount: 1000, date: now, status: \"PENDING\" }\n        ]\n      })\n  \n  [6] Response\n      \"Thank you! Noted your partial payment of Rs.1000.\n       Outstanding balance: Rs.4000...\"\n\nVerification:\n  Check DB: db.dues.findOne({ _id: \"due456\" })\n  ✓ Shows metadata.payments = [{ amount: 1000, ... }]\n  ✓ Shows status = \"VERIFYING\"\n  ✓ Shows outstanding = 4000\n```\n\n---\n\n## Database Schema Summary\n\n### **User Document**\n```javascript\n{\n  _id: ObjectId,\n  email: string,\n  name: string,\n  // Every payment is for THIS user\n}\n```\n\n### **Due Document (Key for Payments)**\n```javascript\n{\n  _id: ObjectId,              // ← BILL IDENTIFIER\n  userId: ObjectId,           // ← WHO OWNS IT\n  customerId: ObjectId,       // ← WHO OWES IT\n  title: string,              // ← WHAT IS IT\n  amount: number,             // ← TOTAL DUE\n  status: string,             // UNPAID → VERIFYING → PAID\n  \n  metadata: {\n    payments: [               // ← PAYMENT HISTORY\n      {\n        amount: number,       // Rs.1000\n        date: Date,           // 2026-08-14T10:30:00Z\n        status: string        // PENDING_VERIFICATION | VERIFIED\n      }\n    ],\n    paymentVerified: boolean, // true = Razorpay confirmed\n    razorpayPaymentId: string // Reference to payment processor\n  }\n}\n```\n\n### **Conversation Document (Audit Trail)**\n```javascript\n{\n  conversationId: string,     // ← CONVERSATION LINK\n  roles: string,              // USER | ASSISTANT\n  message: string,            // \"I paid 1000\"\n  createdAt: Date             // When said\n}\n```\n\n---\n\n## Step-by-Step: How Payment Gets Recorded\n\n```\n1️⃣  User says: \"I paid 1000 rs\"\n         ↓\n2️⃣  Socket receives message + conversationId\n         ↓\n3️⃣  Frontend sends to backend with JWT\n         ↓\n4️⃣  Backend verifies JWT → userId extracted\n         ↓\n5️⃣  LangGraph loads state from checkpointer[thread_id]\n         ↓\n6️⃣  entityResolver identifies due (single or asks)\n         ↓\n7️⃣  Gemini detects: intent=confirm_paid, paymentAmount=1000\n         ↓\n8️⃣  negotiator compares: 1000 < 5000 → PARTIAL_PAYMENT\n         ↓\n9️⃣  actionDispatcher adds to metadata.payments\n         ↓\n🔟 Dues.updateOne({ userId, _id }) → status=VERIFYING\n         ↓\n1️⃣1️⃣ Response: \"Thank you! Partial payment of Rs.1000 noted\"\n         ↓\n1️⃣2️⃣ Frontend plays audio to user\n         ↓\n1️⃣3️⃣ Conversation logged to audit trail\n         ↓\n1️⃣4️⃣ When Razorpay webhook arrives → metadata.paymentVerified = true\n```\n\n---\n\n## Key Safeguards\n\n### **1. User Isolation**\n```javascript\n// ALWAYS filters by userId\ndb.dues.find({ userId: user123 })\n\n// user456 can NEVER access user123's dues\ndb.dues.findOne({ _id: due456, userId: user456 })\n// Returns: null (forbidden)\n```\n\n### **2. Due Disambiguation (NEW)**\n```javascript\n// If multiple unpaid dues exist:\nif (unpaidDues.length > 1) {\n  return { replyText: \"Which bill? 1. bill1, 2. bill2...\" };\n}\n\n// Prevents payment misallocation\n```\n\n### **3. Payment Proof**\n```javascript\n// PARTIAL_PAYMENT status: VERIFYING (not PAID)\n// Prevents premature marking as complete\n\n// Only PAID when:\n// 1. All amount paid, AND\n// 2. Razorpay webhook confirms\n```\n\n### **4. Immutable Audit Trail**\n```javascript\n// Every message stored in Conversations collection\n// Timestamp immutable (createdAt)\n// User's exact words preserved\n```\n\n---\n\n## Quick Debugging Checklist\n\n- [ ] Check JWT token in localStorage\n- [ ] Verify userId in all DB queries\n- [ ] Confirm thread_id matches conversationId\n- [ ] Verify Gemini parsed `paymentAmount`\n- [ ] Check that metadata.payments array exists\n- [ ] Ensure status changed to VERIFYING\n- [ ] Verify Conversation logged both user & AI message\n- [ ] Check if Razorpay webhook updated paymentVerified\n\n---\n\n## What Makes It Secure\n\n1. **Authentication First** - JWT token verified before processing\n2. **Scoped Queries** - All DB operations filtered by userId\n3. **Context Preservation** - LangGraph checkpointer maintains conversation state\n4. **Amount Verification** - Razorpay webhook required for final confirmation\n5. **Immutable History** - Conversation collection never modified\n6. **Explicit Confirmation** - System asks which bill if ambiguous\n\n---\n\n## The Bottom Line\n\n**WHO**: Identified by JWT userId\n**WHAT**: Identified by Due ID (from state or DB lookup)\n**HOW MUCH**: Extracted by Gemini from user message\n**WHEN**: Recorded with server timestamp\n**PROOF**: Pending until Razorpay webhook confirms\n\n✅ **Result**: System always knows exactly who paid what, when, and for which bill.\n"
